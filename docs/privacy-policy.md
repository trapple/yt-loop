# yt-loop プライバシーポリシー

最終更新: 2026-10-25

## 集めていないもの

**yt-loop は利用者の情報を一切集めない。** 開発者を含め、誰かのサーバへ
データを送る経路を持たない。

- 閲覧履歴、視聴した動画、検索語を開発者へ送らない
- 個人を識別する情報を扱わない
- 利用状況の計測 (アナリティクス) を行わない
- 広告を出さない、広告事業者にデータを渡さない

## 端末の中に置くもの

| 置くもの | 場所 | 消えるとき |
|---|---|---|
| ループ範囲を設定した動画の ID と、その範囲 (開始・終了の秒数) とループのオン / オフ | `chrome.storage.local` | 範囲を解除したとき / 拡張を削除したとき |

`chrome.storage.local` に置いた値は、その端末の中にだけ残り、同期されない。
範囲を設定していない動画については何も残さない。

## 求めている権限

| 権限 | 何のために |
|---|---|
| `storage` | 上表の範囲を動画ごとに端末内に置くため |
| `https://www.youtube.com/*` (content script) | プレイヤーの右クリックメニューに項目を足し、シークバーに範囲を表示し、範囲を繰り返し再生するため |

## 第三者への提供

行わない。販売も、譲渡も、共有もしない。

## 子どもの利用について

年齢に関する情報を含め、いかなる個人情報も集めないため、
子どもから情報を集めることもない。

## 変更

変更履歴はリポジトリの Git 履歴で追える。
